Python Chapter 1: 변수와 비교 연산자

학습 목표

  • 대입 연산자(=)와 비교 연산자(==, !=)의 차이를 정확히 이해한다.
  • 조건문(if)에서 비교 연산자가 필요한 이유를 설명할 수 있다.
  • '계산적 사고(Computational Thinking)'를 바탕으로 코드를 예상하고 실행하여 결과를 비교한다.

학습 사례 (STAR)

사례 1: 대입과 비교의 차이, 그리고 에러의 원인

Situation (상황)

파이썬 기초 과정에서 변수 대입(=)과 비교 연산자(==, !=)를 배우는 단계였다. 변수가 마지막 값을 가리킨다는 개념과 조건문의 기본 문법을 익히고 있었다.

Task (과제)

=(넣기)와 ==(물어보기)의 차이를 내 말로 설명하고, if c = 10:처럼 작성했을 때 에러가 나는 이유를 이해하는 것.

Action (행동)

여우(AI)의 도움을 받아 print(boxes == labels)를 직접 입력하고 실행해 보았다. 또한 a = 3, b = 5를 지우고 print(a < b)만 남겼을 때 채점에서 왜 틀렸는지 질문하고 직접 수정해 보았다.

Result (결과)

=와 ==의 차이를 "넣기 vs 물어보기"로 내 말로 정확히 설명할 수 있게 되었다. if 문 뒤에 =를 쓰면 에러가 나는 이유("if는 질문을 기다리는데 =는 질문이 아니라서")를 스스로 깨달았다.
